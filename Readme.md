## Nano Plot 

- Custom graph plotting engine (lines and quadratic)


### Pixel to unit conversion
- The `unit_to_pixel` function calculates the ratio for plotting based current window dimension 
- Screen width specifically to be specific
- With a dimension of 
    - width = 1000 px 
    - height = 900px 
    - our unit to pixel ratio = 512 

### Variable Convention Used
- Equation of a line
    - `y = mx + c` where
    - x = point on the x-axes 
    - y = point on the y-axes 
    - m = gradient (rise/run)
    - c = y-intercept


- Equation of Quadratic Equation
    - `y = ax^2 + bx + c` 
    - a = coefficient of x^2
    - b = coefficient of x 
    - c = constant


### Test Equations
- Line: `y = 2x + 5`
- Quadratic : `y = x^2 - x -12`
